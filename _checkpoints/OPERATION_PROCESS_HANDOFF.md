## 3. index.html 히어로 영역 — 진행 중이던 디자인 조정

Apple 공식 리소스(`developer.apple.com/kr/design/resources/`)의 **Liquid Glass** 원칙(렌즈 효과·스페큘러 하이라이트·적응형 톤·레이어 안 쌓기)을 센티프 민트 브랜드 안에서 참고해 히어로 pill 배지에 적용:

- `.hero-pill` — 반투명 화이트 그라디언트 + blur(14px) + 상단 스페큘러 하이라이트 라인 + 민트 톤 inset shadow
- 버튼(`hero-btns`) 크기 컴팩트화 (16px→12px 패딩, 폰트 16px→14px) — "A: 더 컴팩트하게" 안 채택
- "피트니스 AI 워크스페이스" 텍스트와 메인 헤드라인 사이 간격 확대
- **펄스 점(`.hero-pill-dot`) 완전 삭제** — 처음엔 펄스 링만 제거 요청 → 이어서 점 자체도 삭제 요청, 마지막 명령 실행 중 세션 전환됨

> 이 부분이 **현재 git 미커밋 diff와 정확히 일치**함 (아래 4번 참조).
