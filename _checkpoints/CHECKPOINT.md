## 2. 사용 가이드 (이번 세션 신설, 배포됨)

### 구조 — 3개 탭, 공통은 탭이 아님

```
guide.html         🏋️ 강사 모드   25개 항목  ← lab.html 배너의 진입점
guide-admin.html   🏢 관리자 모드 24개 항목
guide-member.html  👤 회원 모드   13개 항목
```

**중요한 설계 결정 (한 번 뒤집힌 이력 있음)**:
처음엔 `guide-common.html`을 4번째 탭으로 만들었으나 사용자가 반려했다. 확정된 방식은 —

- **공통 기능은 강사·관리자 두 페이지 본문에 "완전히 동일한 내용으로" 중복 수록**한다. 별도 탭 아님.
- 이유: 어느 모드 탭을 눌러도 같은 설명이 보여야 한다. 공통은 강사/관리자에만 해당하고 **회원 모드에는 적용 안 됨**(회원앱은 별개 앱).
- 공통 섹션 3개: `sec-common-start`(회원가입·워크스페이스·모드소개) / `sec-common-my`(프로필·앱설정) / `sec-common-comm`(채팅·공지·메모)
- 목차 라벨은 `공통 · 시작하기` 식으로 접두어를 붙이고, 첫 공통 섹션 상단에 안내 콜아웃이 있다.
- ⚠️ **한쪽만 고치면 안 된다.** 수정 시 두 파일에 동일 적용하고 MD5로 검증할 것:
  ```python
  # 세 섹션의 <section> 내용 해시가 두 파일에서 같아야 함
  re.search(r'<section class="g-section" id="%s">(.*?)</section>' % sid, h, re.S)
  ```

### 관리자 모드 목차 (사용자가 직접 지정한 구조)
`시작하기` / `운영 대시보드`(업무 알림·매출 현황·운영 위험도·공지사항) / `회원관리` / `팀원관리` / `스케줄 관리` / `AI`

### 화면 캡처 — 아직 전부 자리만 잡힌 상태
모든 항목에 `.g-capture` 플레이스홀더(`📸 캡처 예정 — 화면명` + 빨간 표시 위치 설명)가 들어가 있다.
- 초기엔 HTML/CSS로 폰 목업을 그렸으나 **"실제 개발된 화면과 너무 다르다"고 반려됨.** 목업 재시도 금지.
- 사용자가 테스트플라이트로 맥북에 앱을 설치해주면 → 실제 화면 탐색·캡처 → 이미지 위에 빨간 표시 → 플레이스홀더 교체.

### 콘텐츠 작성 원칙
- 앱 소스(`~/Desktop/작업파일/GRIP_NOTE-main/`)의 **실제 한글 UI 문자열을 grep으로 확인하고** 쓴다. 추측 금지.

## 3. Supabase (2026-07-22 신규)

### 상태
- 프로젝트: `https://eyjzurevdslukzfkimfg.supabase.co` — **살아있음**, `articles` 테이블에 글 7건 존재
- 키는 `supabase-client.js`에 있음 (anon key는 공개 키라 노출 정상)

### 일시정지 문제와 해결
- **원인**: 무료 플랜은 7일간 API 요청이 없으면 자동 정지. 개발 중이라 DB를 두드릴 일이 없어 반복됨.
- ⚠️ **잠들면 방문자로는 절대 못 깨운다** — DNS부터 내려가서(NXDOMAIN) 요청이 서버에 도달조차 못 한다. **대시보드 수동 Restore만이 유일한 해제 방법.**
- **해결**: `.github/workflows/supabase-keepalive.yml` — 매일 09:20 KST에 REST API 요청 1건. 첫 실행 success 확인됨.
  - URL·키를 `supabase-client.js`에서 grep으로 추출(단일 출처 유지)
  - 200이 아니면 실패 처리 → GitHub 알림 메일
  - `workflow_dispatch`로 수동 실행 가능 (Actions 탭 → Run workflow)
- ⚠️ **사각지대**: GitHub은 저장소가 **60일간 활동 없으면 스케줄 워크플로를 자동 비활성화**한다. 그러면 ping이 멈추고 7일 뒤 또 잠긴다. 비활성화 시 메일이 오니 Actions 탭에서 다시 켤 것.
- `actions/checkout`은 **v5 이상**을 쓸 것. v4는 Node 20 기반이라 deprecation 경고가 뜬다.

## 4. 함정·주의

- **공통 섹션은 guide.html + guide-admin.html 두 곳에 복제** — 한쪽만 고치면 깨짐 (MD5 검증)
- **FAQ는 pricing + consulting 두 파일에 복제** / **CTA 밴드는 4파일에 복제** — 수정 시 함께
- style.css 수정 → 6개 HTML의 `?v=` 올리기
- **Flutter SDK 미설치** — `flutter analyze`/테스트 불가. 앱 소스는 grep으로 문자열 확인만 가능.
- **앱 소스는 git 저장소가 아님** — 수정 시 롤백 불가. 애초에 수정 금지(개발자님 담당).
- 미사용 CSS 검사: `<style>`에서 `.class` 추출 → 마크업 class 토큰 + `<script>` 본문에 없으면 죽은 클래스
- 가이드 검증 3종 세트: 목차 앵커 무결성 / 죽은 CSS / 공통 섹션 해시 일치
- `nth-child` 금지 관례 — 고유 클래스 + 인라인 `--d` 지연 사용
- 작업 폴더(`ssentif-redesign`) 밖 파일을 대량 수정하려 하면 **자동 승인 정책에 차단됨.** 우회하지 말고 사용자에게 알릴 것.
