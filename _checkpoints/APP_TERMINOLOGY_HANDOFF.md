## 배경

홈페이지와 사용 가이드의 용어를 전부 통일했는데, **앱 화면은 아직 옛 용어를 쓰고 있어 서로 어긋난 상태**입니다.

예를 들어 가이드는 `[담당 강사 배정]`이라고 안내하는데 실제 버튼은 `담당 코치 배정`이고, 회원앱은 `"코치 승인 후 확정돼요"`라고 뜹니다. 같은 기능이 두 이름으로 불리면 사용자 경험이 깨지므로 앱 쪽도 맞춰주셔야 합니다.

## 변경 요청

| 개념 | 현재 | **변경** | 코치앱 | 회원앱 |
|---|---|---|---|---|
| 수업하는 사람 | 코치 | **강사** | 280건 | 189건 |
| 워크스페이스 구성원 | 직원 | **팀원** | 86건 | — |

### 제외 대상 (바꾸지 말 것)

목업/테스트용 인명이라 그대로 둬야 합니다.

```
김코치 (12건)   나코치 (11건)   박코치 (5건)
```

### 함께 수정해야 할 테스트

```
ssentif-coach/test/features/operations/staff_card_test.dart:64
  expect(find.text('코치'), findsOneWidget);   →   '강사'
```

이거 하나만 화면 문자열을 직접 단언합니다. 나머지 테스트의 `코치`는 전부 목업 인명이거나 `test('...')` 설명 문구라 영향 없습니다.

### 안전성

한글 문자열·주석만 바뀝니다. Dart 식별자는 전부 영문이라 무관합니다.

```
coachName, CoachMode, coachModeNotifierProvider,
assign_coach_sheet.dart, adminScheduleScopeProvider ...  ← 건드리지 않음
```

## 추가로 판단이 필요한 앱 자체 불일치

용어 조사 중 발견한, **앱 코드 안에서 이미 혼용 중인** 항목들입니다. 이번 기회에 정리하시길 권합니다.

### 1. 같은 역할을 두 이름으로 부름 🔴

`ssentif-coach/lib/domain/enums/staff_role.dart`

```dart
enum StaffRole {
  owner('owner', '대표'),      // ← label
  admin('admin', '관리자'),
  staff('staff', '직원');
}

String get displayLabel => switch (this) {
  StaffRole.owner => '소유자',   // ← 같은 owner인데 '대표' vs '소유자'
  StaffRole.admin => '관리자',
  StaffRole.staff => '코치',     // ← label은 '직원', displayLabel은 '코치'
};
```

- `owner` → **대표** / **소유자** 두 이름
- `staff` → **직원** / **코치** 두 이름

화면마다 어느 쪽이 나오는지 달라서, 사용자는 같은 등급을 네 가지 이름으로 보게 됩니다.

### 2. 팀원 vs 직원 혼용

같은 화면 안에서도 섞여 있습니다.

```
staff_management_screen.dart
  title: '팀원 관리'          ← 화면 제목
  '워크스페이스에 참여 중인 팀원들을 관리할 수 있습니다.'
  ...
  barrierLabel: '직원 상세'    ← 같은 파일
  '퇴직 직원이 없습니다.'
  '조건에 맞는 직원이 없습니다.'
```

가이드 문서는 **팀원**으로 통일해뒀습니다.

### 3. 하단 탭 라벨

가이드에서는 사용자가 화면에서 찾을 수 있도록 `[팀원]`, `[팀원 초대]` 같은 **실제 버튼 라벨을 그대로** 인용했습니다. 앱에서 라벨을 바꾸시면 알려주세요 — 가이드도 함께 고쳐야 합니다.

## 참고: 가이드에서 이미 정정한 앱 관련 오류

가이드를 쓰면서 앱 소스와 대조해 바로잡은 것들입니다. 앱 쪽 확인이 필요할 수 있습니다.

| 가이드 초안 (틀림) | 실제 앱 |
|---|---|
| 매칭 / 매칭하기 | **연동** (코치앱 14건·회원앱 20건). `매칭` 문자열은 앱에 **0건** |
| 생성회원 / 매칭회원 | **미연동** / **연동 완료** |
| 회원 휴대폰번호로 검색해 연결 | 회원이 발급받은 **연동 코드**를 보여주는 방식 |
| 루틴 보관함 | 존재하지 않는 기능 |
