### 확정된 핵심 결정사항 (재작업 시 유지할 것)

- **정기결제일 변경**: "결제일에 해당 날짜가 없는 달(예: 윤달, 31일)에는 결제일이 그 달의 말일 기준으로 변경될 수 있습니다." (예시 상세 설명 없이 짧게)
- **팀원 과금 시점**: 초대 **수락** → 관리자 **최종 승인** → 정식 팀원(재직) 전환 시점부터 과금 시작. 수락만 하고 미승인 상태(대기)는 과금 안 함.
- 회원(고객) 수는 요금과 무관하다는 부연 설명 문구는 넣지 않음 — "과금 대상은 워크스페이스의 정식 팀원(관리자·강사) 수입니다"로 간결하게.
- **법적 방어 조항(지식재산권/책임제한/보증부인 등) 대거 보강했다가 전량 삭제됨** — 사용자가 "너무 부정적/과하다"는 이유로 되돌림. 재추가 요청이 없는 한 다시 넣지 말 것.
- 분쟁 해결 관할은 "회사 본점 소재지"가 아니라 **이용자 주소지 관할**(전자상거래법 표준)로 확정.

6. 개인정보의 파기
7. **만 14세 미만 아동의 개인정보 처리** — 전 연령 이용 가능 서비스 기준 업계 통상 규약(법정대리인 동의 → 확인 → 열람/정정/파기)으로 작성. "성인 대상 서비스라 미성년 가입 안 받음" 논리 아님.
8. 정보주체와 법정대리인의 권리·의무 및 행사방법
9. 개인정보의 안전성 확보조치
10. 쿠키(Cookie)의 운용
11. **추가적인 이용·제공 판단기준** (신설) — 개인정보보호법 제15조③·17조④, 시행령 제14조의2 기준 4가지 고려사항
12. 개인정보 보호책임자 — **손평화 (CTO)**, 카카오톡 채널 "센티프 SSENTIF"

- 처리 목적 중 "마케팅 및 서비스 개선" 항목에서 "(선택 동의 시에 한함)" 문구 삭제됨
- 필수 수집항목에서 "(자체 가입 시)" 문구 삭제, "센터 이용 이력" 뒤에 "등" 추가
- 위탁업체 표는 **토스페이먼츠 + 카카오/네이버만** (Supabase, Vercel 등 인프라 벤더는 명시하지 않기로 함 — 재추가 시 사용자 확인 필요)

## 남은 일 / 다음 세션 참고

1. **아직 배포 전** — `git add . && git commit && git push`는 사용자가 명시적으로 "배포해줘"라고 할 때만 진행할 것.
2. 실제 배포 전 **변호사 검토 권장** — 특히 환불규정·분쟁해결 조항.
3. `개인정보 보호책임자`가 손평화(CTO)로 바뀌었는데, 전화번호·이메일 등 구체적 연락처는 아직 카카오채널로만 되어 있음. 필요시 직통 연락처 추가 여부 확인.
4. 스토어 등록 체크리스트(`store-submission-todo` 메모리)의 "개인정보처리방침 URL(`ssentif.kr/privacy`) · 지원 URL(`ssentif.kr/support`)" 항목 중 **privacy는 이번 작업으로 해소 가능** (배포 후 `https://www.ssentif.kr/privacy.html`). `/support`는 별도로 미해결.
