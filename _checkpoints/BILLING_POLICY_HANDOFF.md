# 결제 정책 핸드오프 — 4티어 요금제 결제 방식 (개발자 전달용)

> **2026-07-30 기획 확정.** 플랜 구조·가격은 `CLAUDE.md` §요금제 구조(4티어) 참조.
> 이 문서는 **결제 플로우·과금 타이밍**만 다룬다. 예시는 전부 "앵커일 1일 · 주기 30일 · 변동일 15일(잔여 50%)" 가정.

## 0. 가격 기준표

| 플랜 | 가격 | 비고 |
|---|---|---|
| FREE | 0원 | 1인 · 카드 불필요 |
| STANDARD | 20,900원/월 | 1인 |
| TEAM | 24,900원/월 × 인원 | 2인 이상 · owner 포함 전원 |
| ENTERPRISE | 개별 계약 | 이 문서 범위 밖 |

- STANDARD ↔ TEAM 1인 차액 = **4,000원/월**.

## 1. 공통 규칙

1. 월 단위 **선불 자동결제**. 연간 플랜 없음. **환불 없음**.
2. 결제일(앵커) = 최초 유료 결제일. 변동은 §2 규칙으로만.
3. 과금 대상 = 워크스페이스 **팀원 수**(owner 포함). 회원 수는 무관.
4. 초대 게이트: 결제수단 미등록 시 2번째 인원 **초대 발송 자체가 불가**.
5. 좌석 과금 시작 = 초대 **수락** 시점. 발송만 되고 미수락인 좌석은 미과금.
6. **추가 과금은 즉시 일할 결제**: 변동 시점에 `단가 × (다음 결제일까지 남은 일수 ÷ 현 주기 총 일수)`를 바로 결제 → 다음 결제일부터 전원 합산 **정상가**로 일원화.
7. **인원 감소는 즉시 반영 안 함**: 당월 결제분 유지(환불 없음) → 다음 결제일에 실제 인원으로 재계산.
8. **좌석 승계 없음**: 같은 주기 안에 1명 나가고 1명 들어와도 감소(환불 없음)와 추가(일할 즉시 결제)를 **각각** 적용.
9. 무료 체험 없음("14일 무료 체험" 재도입 금지 — 기존 확정 정책).

## 2. 결제일(앵커) 규칙 — 말일 축소 · 영구 고정

- 해당 월에 앵커 날짜가 없으면 **그 달 말일에 결제하고, 앵커를 그 날짜로 영구 고정**한다. 축소만 되고 되돌아가지 않는다.
- 예: 3/31 최초 결제 → 4월엔 31일이 없으므로 **4/30 결제, 앵커 30 고정** → 5/30 · 6/30 … → 2월엔 30일이 없으므로 **2/28 결제, 앵커 28 고정** → 이후 매월 28일.
- 윤년 2월(29일)을 만나면 같은 규칙으로 29에 고정됐다가, 평년 2월에서 28로 최종 고정.
- ❓ **확인 1건**: 12/31 시작처럼 바로 다음 달(1월)에 31일이 **있는** 경우 → "날짜가 없는 달을 만났을 때만 축소"로 해석해 1/31 결제로 정리했다. 다른 의도(무조건 다음 달부터 30일)라면 알려줄 것.

## 3. 케이스별 플로우

| # | 케이스 | 변동 시점 결제 | 다음 결제일부터 |
|---|---|---|---|
| A | FREE → STANDARD | **20,900원 전액 즉시**(그날이 새 앵커) | 매월 20,900원 |
| B | 처음부터 STANDARD 가입 | A와 동일(가입일 = 앵커) | 매월 20,900원 |
| C | 처음부터 TEAM(무료 owner + 첫 초대) | 첫 팀원 **수락일**에 24,900×2 = **49,800원 즉시**(그날이 앵커) | 매월 49,800원 |
| D | STANDARD → TEAM (15일에 1명 추가) | 신규 좌석 24,900×50% = 12,450 + **owner 차액** 4,000×50% = 2,000 → **합계 14,450원 즉시** | 2인 = 49,800원 |
| E | TEAM 3인 → 4인 (15일) | 신규 좌석 24,900×50% = **12,450원 즉시** | 4인 = 99,600원 |
| F | TEAM 4인 → 3인 (15일) | **결제 없음**(환불도 없음, 당월 4인분 유지) | 3인 = 74,700원 |
| G | 교체: 15일에 1명 나가고 1명 들어옴 (4인 유지) | F + E 각각 적용 = 환불 없음 + 신규 **12,450원 즉시** | 4인 = 99,600원 |
| H | TEAM에서 팀원 전원 이탈 → owner 1인 | 결제 없음(당월 유지) | **자동 STANDARD 전환** = 20,900원 |
| I | STANDARD → FREE (수동 강등) | 결제 없음. **자동 강등 없음 — 사용자가 직접 신청**해야 함 | 주기 종료 후 FREE 제한 **전면 재적용**(연동 3명·조회 30일·AI 제한) |
| J | TEAM 워크스페이스 해지 | 결제 없음 | 주기 종료까지 사용 → FREE 강등, 팀 기능 잠금(세부 §6-2) |
| K | 결제 실패 | §4 참조 | — |

- D·E의 일할 결제는 같은 주기에 여러 번 발생 가능(15일에 1명, 20일에 1명 → 각자 시점 기준으로 각각 일할).
- G 보충: 당월 실질 4.5좌석을 결제하게 되는 구조가 맞음(기획 확인 완료 — 승계 없음).

## 4. 결제 실패 플로우

1. 결제일(D일) 실패 → **D+1 / D+2 / D+3, 매일 오전 11시**에 재결제 시도 (총 3회).
2. 재시도 기간(3일) 동안 서비스는 **정상 사용 가능**.
3. D+3 시도까지 실패하면 → **즉시 무료 플랜(FREE)으로 강제 강등 + 기능 제한 적용**.
4. 강등 후 사용자가 다시 결제하면 신규 결제와 동일하게 취급(그날이 새 앵커) — *제안, §6-5 확인 필요*.

## 5. 강등(다운그레이드) 규칙

- **자동 강등은 없다**(결제 실패 강등 제외). 하위 플랜 전환은 사용자가 직접 신청.
- 수동 강등 시: 현 주기 종료까지 기존 플랜 유지(환불 없음) → 종료 후 하위 플랜의 기능 제한을 **그대로 재적용**.
- 예외적 자동 전환 1건: TEAM에서 1인만 남으면 다음 결제일에 **자동 STANDARD**(더 싼 요금 자동 적용).
- 어떤 강등에서도 **데이터는 삭제되지 않는다**(조회·기능만 제한) — 기존 확정 정책.

## 6. 구현 시 결정 필요 (기획 확인 대기)

1. FREE 강등 시 연동 3명 초과분 처리 — 어떤 연동이 활성으로 남는가(사용자 선택 UI vs 최근 활동순 자동).
2. TEAM 워크스페이스가 FREE로 강등될 때 owner 외 팀원 계정의 접근 처리(잠금 방식·안내).
3. 일할 금액의 원 단위 처리(절사 제안).
4. §2의 ❓(31일 유지 해석) 확인.
5. §4-4(강등 후 재결제 = 앵커 리셋) 확인.
